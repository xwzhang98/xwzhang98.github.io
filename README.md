# xwzhang98.github.io

Personal academic website of **Xiaowen Zhang** — Physics PhD candidate at Carnegie Mellon University, working on machine learning for cosmological simulations.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme. Deployed via GitHub Pages.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

## Content map

- `_pages/about.md` — homepage bio
- `_bibliography/papers.bib` — publications (rendered by jekyll-scholar)
- `_news/` — news items shown on the homepage
- `_projects/` — research project pages
- `_pages/teaching.md` — teaching and mentoring
- `_data/cv.yml` + `assets/pdf/Xiaowen_Zhang_CV.pdf` — CV page
